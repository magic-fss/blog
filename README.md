# 项目简介

本项目是个人独立开发的现代化无服务器博客系统，基于 Cloudflare 全栈开发者平台从零搭建而成。

项目依托 Cloudflare Pages 做静态资源托管、Cloudflare Workers 承载后端无服务器接口服务、D1 轻量化 SQLite 数据库存储业务数据、R2 对象存储托管图片等静态资源。只需准备一个域名解析指向 Cloudflare 服务，即可快速部署专属个人博客，无需购买服务器、无需运维配置，开箱即用。

## 在线演示

个人演示站点：https://fss.dpdns.org

## 功能特性

- **用户权限与登录管理**：集成 登录，首位注册用户自动授予管理员权限，后续注册用户默认普通访客权限，权限划分清晰。
- **富文本内容创作**：内置功能完善的可视化编辑器，支持图文混排、格式编辑，满足博客文章创作全场景需求。
- **实时本地草稿**：自动本地实时保存写作草稿，多篇文章草稿相互隔离，避免内容丢失。
- **文章隐私权限**：支持设置文章仅本人可见，可作为私人笔记、隐藏草稿使用，同时支持多设备同步查看。
- **一体化图片管理**：支持拖拽、粘贴两种方式上传图片，自动对接兼容 S3 协议的对象存储（Cloudflare R2），上传后自动生成可直接引用的图片链接。
- **自定义友好路由**：支持为单篇文章设置自定义访问别名，实现如 `https://fss.dpdns.org/about` 这类简洁优雅的链接地址。
- **隐藏文章配置**：可将指定文章设置为不展示在首页列表，适合归档内容、临时文案留存。
- **友情链接管理**：内置友链后台管理功能，系统每 20 分钟自动检测友链可用性，自动更新在线 / 失效状态。
- **完整评论系统**：支持评论层级回复、管理员删除违规评论，具备完善的评论管理能力。
- **Webhook 消息通知**：可自定义配置 Webhook 地址，有新评论时实时推送消息提醒。
- **智能封面识别**：自动抓取文章内首张图片，作为博客列表页的封面展示图，无需手动单独设置。
- **标签自动解析**：写作时直接输入 `#博客 #Cloudflare` 这类格式，系统自动解析并生成独立标签分类。
- **全链路类型安全**：基于 TypeScript 封装公共类型包，客户端与服务端共享类型定义，从前端到后端实现全链路类型约束，减少接口报错。

更多个性化功能可自行部署体验与二次开发。

## 开发部署文档

### 本地开发快速上手

```bash
# 1. 克隆项目到本地
git clone https://github.com/magic-fss/blog.git && cd blog

# 2. 安装项目依赖
bun install

# 3. 环境变量配置
cp .env.example .env.local
# 手动编辑 .env.local 文件，填入个人配置参数
```

编辑完成配置文件后，启动本地开发服务：

```bash
# 启动本地开发服务器
bun run dev
```

浏览器访问 `http://localhost:5173` 即可进行项目开发与功能调试。

### 项目测试

内置完整测试用例，可执行以下命令校验项目稳定性：

```bash
# 执行全套测试（前端客户端 + 后端服务端）
bun run test

# 仅运行后端服务单元测试
bun run test:server

# 运行测试并生成代码覆盖率报告
bun run test:coverage
```

### 云端一键部署

封装自动化部署脚本，一条命令即可将前后端统一部署至 Cloudflare 平台：

```bash
# 全量部署：前端页面 + 后端服务一次性部署
bun run deploy

# 仅单独部署后端 Worker 服务
bun run deploy:server

# 仅单独部署前端静态页面
bun run deploy:client
```

#### 必配环境变量

部署前需配置以下核心参数：

- `CLOUDFLARE_API_TOKEN`：个人 Cloudflare 接口访问令牌
- `CLOUDFLARE_ACCOUNT_ID`：个人 Cloudflare 账号唯一 ID

#### 可选自定义环境变量

可按需修改项目资源命名，不配置则使用默认值：

- `WORKER_NAME`：后端 Worker 服务名称（默认：`rin-server`）
- `PAGES_NAME`：前端 Pages 站点名称（默认：`rin-client`）
- `DB_NAME`：D1 数据库实例名称（默认：`rin`）
- `R2_BUCKET_NAME`：R2 对象存储桶名称，配置后自动关联 S3 相关参数；不配置则不启用对象存储自动关联。

#### 部署脚本自动执行能力

部署脚本已封装自动化逻辑，无需手动操作：

- 自动检测 D1 数据库，不存在则一键创建
- 配置 R2 存储桶名称后，自动推导匹配对应存储参数
- 自动打包部署后端至 Cloudflare Workers
- 自动构建前端项目并部署至 Cloudflare Pages
- 自动执行数据库迁移脚本，初始化数据表结构

### GitHub 自动化工作流

项目内置全套 GitHub Actions 自动化流程，提交代码后自动触发：

- **`ci.yml`**：代码提交 / 合并 PR 时，自动执行类型检查、代码格式校验
- **`test.yml`**：自动运行前后端全套测试，生成测试覆盖率报表
- **`build.yml`**：自动打包编译项目源码，为部署做准备
- **`deploy.yml`**：编译完成后自动部署到 Cloudflare Pages 与 Workers

#### 流水线必备密钥配置

需在仓库 **设置 → 密钥与变量 → 操作密钥** 中添加：

- `CLOUDFLARE_API_TOKEN`：具备 Workers、Pages 权限的 Cloudflare 令牌
- `CLOUDFLARE_ACCOUNT_ID`：Cloudflare 个人账号 ID

#### 流水线可选变量配置

可自定义站点与资源信息：

- `WORKER_NAME`、`PAGES_NAME`、`DB_NAME`：自定义云资源名称
- `NAME`、`DESCRIPTION`、`AVATAR`：博客站点基础信息配置
- `R2_BUCKET_NAME`：绑定专属 R2 存储桶
